# Base Frame

## Category

［同一产品/服务类别。］

## Who — behaviour

［核心用户；行为、关系、频率。不换行业。］

## Occasion

［主要场景/时刻。］

## Job-to-be-done

［用户真正要完成的事。］

## Existing substitute

［最便宜的现有替代 + 成本。］

## Primary value

［时间 / 尊严 / 安全 / 可预测性 / 成本。只选一个主值。］

## Constraints

- 法规/适航：
- 基础设施：
- 预算：
- 身体/空间：
- 环境/天气：

## Not in this campaign

- ［不换品类。］
- ［不换核心用户。］
- ［不把运营商/监管/社区/保险当成单独 run；它们是约束透镜。］
