# Positioning Table (one idea per table)

Use when the user wants one idea readable as a positioning table, like a design-review slide.

## Format

## ［ID］· ［Title］

**［STATUS］** · ［family］ · ［originating reading or lens］

［For a reframed card, state the insight retained from the brief. Include score, secondary lens and shortlist rank only when applicable.］

| 项 | 内容 |
|---|---|
| **Who** | ［role］；［occasion］；［frequency］ |
| **行为** | ［current behaviour + workaround］ |
| **现有替代** | ［cheapest substitute + cost/effort］ |
| **空位** | ［decision-changing gap］ |
| **What** | **［one short promise; for Chinese, aim for 15 characters or fewer］** |
| **How** | ［mechanism / ritual / product action］ |

- Proof：［metric + threshold］
- Kill：［testable kill condition］

## Rules

- One table per idea; never combine several ideas into one wide table.
- Who must be behavioural, not demographic.
- 行为 must include the workaround, not only the complaint.
- 现有替代 must include cost or effort; "none" is not enough.
- 空位 must change a decision (time, place, object, behaviour), not just satisfaction.
- What is one promise, not a slogan; How is what actually delivers it.
- Keep Proof and Kill below the table; do not hide them in another file.
- No `…` truncation.
